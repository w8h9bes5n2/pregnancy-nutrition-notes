# 深圳三代试管必做清单：流程+费用+时间全攻略

> 更新时间：2026-09-15 (UTC+8)

一、三代试管流程

**有任何一代，二代,三代试管/出国助孕生子相关问题，可点击咨询按钮与我们联系，我们将24小时在线为您一对一详细解答助孕生子流程。**

1. 前期检查与评估

女方检查：月经第2-5天检查性激素六项、AMH、传染病筛查、TORCH、染色体等；非经期进行宫颈癌筛查（HPV/TCT）、宫腔镜、输卵管造影等。

男方检查：精液分析、精子DNA碎片率、染色体、传染病筛查等。

评估目的：排除禁忌症，制定个性化促排方案。

2. 促排卵与监测

药物促排：根据女方年龄、卵巢功能选择拮抗剂方案、长方案等，用药10-14天。

卵泡监测：通过B超和激素检测调整药量，避免OHSS风险。

3. 取卵/取精与体外受精

取卵：B超引导下经阴道穿刺取卵，全程无痛或静脉麻醉。

取精：男方同步取精，优化处理后备用。

受精方式：常规IVF或ICSI（显微注射），根据精子质量选择。

4. 胚胎培养与筛查

囊胚培养：胚胎培养至第5-7天形成囊胚。

PGT检测：通过PGT-A筛查染色体非整倍体，PGT-M检测单基因遗传病，剔除异常胚胎。

5. 胚胎移植与黄体支持

移植时机：根据子宫内膜容受性检测（ERT）结果选择最佳窗口期。

移植操作：无痛操作，移植1-2枚优质胚胎。

黄体支持：术后使用黄体酮、雪诺酮等药物保胎。

6. 验孕与孕期管理

验孕：移植后14天测血HCG，21天复查翻倍情况，30天B超确认胎心。

孕期管理：高龄产妇需加强产检，监测血压、血糖，预防妊娠并发症。

二、费用明细

1. 前期检查费用：5000-10000元

女方检查：3000-6000元（含染色体、AMH、宫腔镜等）。

男方检查：2000-4000元（含精液分析、精子DNA碎片率等）。

2. 药物费用：10000-20000元

促排卵药物：国产药1-1.5万元，进口药2-3万元。

黄体支持药物：2000-3000元。

3. 手术与实验室操作费用：40000-60000元

取卵/取精手术：1-1.5万元。

胚胎培养与筛查：PGT-A筛查单个胚胎3000元，5-8个胚胎总费用3-5万元。

胚胎移植：1-2万元（含移植手术、术后监测）。

4. 其他费用：5000-10000元

胚胎冷冻与保存：首年2000-5000元，后续每年1000-3000元。

麻醉费、手术耗材等：2000-5000元。

总费用范围：10-20万元（含隐性收费，如VIP咨询费、加急费等）。

三、时间安排

1. 前期检查：1-2周

女方需分经期和非经期两次检查，男方一次性完成。

2. 促排卵周期：10-14天

根据卵泡发育情况调整用药，需定期返院监测。

3. 取卵/取精与受精：1天

取卵后3-6小时完成受精，胚胎培养5-7天。

4. 胚胎筛查与移植：7-14天

PGT检测需1-2周，移植需根据子宫内膜情况安排。

5. 验孕与孕期管理：14天后

移植后14天验孕，成功后进入常规产检流程。

总周期时间：3-4个月（含等待结果、调整方案等）。
